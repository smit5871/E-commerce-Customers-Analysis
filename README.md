# E-Commerce Customer Analysis

## Project Overview
This project analyzes e-commerce customer data to understand customer behavior, spending patterns, and purchasing trends using data analysis and machine learning.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Power BI
- Streamlit

## Project Features
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Customer Spending Analysis
- Data Visualization
- Linear Regression Model
- Customer Spending Prediction
- Interactive Power BI Dashboard
- Streamlit Prediction App

## Machine Learning
A Linear Regression model is used to predict customer yearly spending based on customer-related features.

## Project Files
- Jupyter Notebooks – Data analysis and machine learning
- `app.py` – Streamlit application
- `ecommerce_model.pkl` – Trained machine learning model
- `.pbix` – Power BI dashboard
- Dataset – E-commerce customer data
